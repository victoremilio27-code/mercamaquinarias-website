<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| nuestra página → iframe de CardNet | Distinto origen; nuestro JS no puede leer el formulario |
| iframe → nuestra página | `postMessage`: solo se acepta el origen exacto que dio el servidor |
| servidor → DOM | Marcas, textos de error y avisos se pintan como HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-36 | Spoofing | mensaje falso de «terminé» | mitigate | Origen exacto; aun así solo dispara la confirmación: el servidor decide leyendo el Customer |
| T-06-37 | Information disclosure (PCI) | campos de tarjeta en nuestra página | mitigate | Ninguno existe; la barrera de 06-01 corre sobre `assets/` y los `.html` |
| T-06-38 | Tampering (XSS) | textos del servidor | mitigate | `esc()`; el `src` del iframe por propiedad, no por HTML |
| T-06-39 | Tampering | doble pago por doble clic | mitigate | Bandera en el navegador + `EN_CURSO` y `UniqueID` en el servidor |
| T-06-40 | Tampering | redirección abierta | mitigate | `location.assign` solo si el origen de `redireccion` es exactamente el de CardNet que dio el servidor |
| T-06-41 | Repudiation | casilla marcada por defecto | mitigate | Desmarcada siempre; solo con tarjeta; texto del servidor |
