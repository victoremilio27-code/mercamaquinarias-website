## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → servidor | El navegador solo avisa y elige una tarjeta guardada por id |
| servidor → CardNet | El token viaja del Customer al purchase sin pasar por el navegador |
| CardNet → transición | Solo un «aprobado» explícito llega a `confirmarPago` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
