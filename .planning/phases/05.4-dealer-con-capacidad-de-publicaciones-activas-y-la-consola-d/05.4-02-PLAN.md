<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL → panel (`?ampliar=`) | valor no confiable que decide qué se abre |
| panel → POST /api/membresias/:id/ampliar | el navegador solo propone cantidad y método |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05.4-08 | Tampering | `?ampliar=` con id ajeno o inyectado | mitigate | solo abre si coincide exactamente con una membresía de `MEMBRESIAS`; nunca se pinta el valor |
| T-05.4-09 | Tampering | importe mandado desde el navegador | mitigate | el cuerpo lleva solo `cupo` y `metodo`; el servidor recalcula (plan 01) |
| T-05.4-10 | Information Disclosure | XSS con datos del servidor en la sección | mitigate | todo lo pintado pasa por `esc()`; sin `innerHTML` con valores sin escapar |
| T-05.4-11 | Spoofing | presentar un 202 como ampliación hecha | mitigate | el 202 solo dice «en espera» y deja el pago en «Pagos en espera» |
</threat_model>
