## Infraestructura

| Propiedad | Valor |
|-----------|-------|
| **Marco** | Arnés propio con contadores y `process.exit` (`tools/probar-telefono.js`; los textos y avisos en `tools/probar-contactos.js`), `tools/prueba-chat.js`, y puppeteer (`tools/auditar-*.js`) |
| **Configuración** | base desechable en `.tmp/prueba-telefono/`; `MERCA_DB`, `MERCA_CORREO=archivo`, `MERCA_SECRETO` fijados y `MERCA_SMS*`/`BREVO_API_KEY` borrados ANTES de `require('./db.js')`; el SMS se enciende a mitad de la ejecución con `MERCA_SMS=archivo` y se apaga en `finally` |
| **Reloj** | ninguna expectativa depende de la fecha: lo vencido se fuerza a `PASADO = 2000-01-01T00:00:00.000Z`, lo vigente a `FUTURO = 2999-01-01T00:00:00.000Z`; «hace un día» se calcula en SQL (`strftime(…, 'now', '-1 day')`); el tope diario es una ventana de 24 h de `db.permitir`. Ya no existen `ponerEnfriamiento`, `enEnfriamiento` ni `accionSmsReciente`. `grep -c "Date.now()" tools/probar-telefono.js` = 0 |
| **Asincronía** | las rutas públicas responden antes de buscar la cuenta (`setImmediate`): la prueba espera un tick antes de leer `.tmp/sms/` o la base |
| **Navegador** | SMS apagado: `auditar-flujos` y `auditar-permisos` contra el 8080 (como el CI). SMS encendido: `auditar-telefono` levanta su propio servidor en el 8091 con `MERCA_SMS=archivo` y base en `.tmp/auditar-telefono/` |
| **Comando rápido** | `npm run telefono:probar` |
| **Suite completa** | todas las baterías del job `pruebas` de `.github/workflows/desplegar.yml` (`check:encoding`, `taxonomia`, `facturas:letras`, `precios:probar`, `seguridad:probar`, `dealer:probar`, `bitacora:probar`, `cuenta:probar`, `telefono:probar`, `contactos:probar`, `catalogo:probar`, `facturas:probar`, `pagos:probar`, `metricas:probar`, `transferencia:probar`, `publicacion:probar`, `renovacion:probar`, `recordatorios:probar`, `capacidad:probar`, `cardnet:probar`, `chat:probar`); con el sitio de demostración en 8080, `npm run auditar` (incluye `auditar-telefono`), `npm run check` y `npm run check:motion` |
| **Duración estimada** | ~10 s rápido; ~5 min completo |
